# 示例自然语言输入

## 完整输入

```text
创建一个倾角改变轨道机动规划场景，从2022年11月5日开始，初始轨道半长轴6570000米，偏心率0，倾角28度，先抬升远地点到42160000米，再圆化轨道，最后在升交点把倾角降到0度，并运行MCS。
```

## 较口语化输入

```text
帮我建一个从低轨转到GEO并把倾角从28度降到0度的任务，开始时间是2022年11月5日。
```

## 多卫星轨道显示输入

```text
创建两颗卫星绕地球转一圈，高度分别为500km和800km，倾角分别为45度和60度。
```

## DeepSeek 时间理解输入

```text
从2022年11月5日开始，创建一颗高度500km倾角45度的卫星，持续三天。
```

```text
明天开始创建一颗高度500km倾角45度的卫星，绕地球5圈。
```

## 地面站创建输入

```text
创建一个北京地面站，纬度39.9度，经度116.4度，高度50米。
```

## 卫星-地面站可见性输入

```text
创建一颗高度500km倾角45度的卫星和一个北京地面站，计算它们之间的可见性。
```

## 模糊输入

```text
帮我做一个转移到GEO的任务。
```

模糊输入会触发默认参数假设提示，后续可以扩展成真正的多轮追问。

## 暂不支持输入

```text
帮我设计一个月球基地。
```

暂不支持输入会被明确拒绝，不会强行套用现有模板。
